# How to run a tournament

Follow the steps in order. Skip anything you have already done. You can reopen this guide from the left menu at any time.

## 1. Create a tournament

1. Open Tournaments in the left menu and choose Add tournament.
2. Enter a name, such as “Bubušinac 2027”. A cover image is optional.
3. Save, then open the tournament card.

## 2. Add players

1. Open Players in the left menu and add a player.
2. Enter their name, birth year and club. Birth year is required; photos and contact details are optional.
3. Choose an existing club name when available. Check any similar-name suggestion and click it to accept it.

Correct clubs before registration: editing a profile does not change the club saved in an existing registration.

## 3. Create categories

1. Open the tournament, then Categories → Add category.
2. Enter a name such as “Singles 40+”. Choose singles or doubles.
3. Choose direct knockout or groups followed by knockout. For groups, set the number of groups and qualifiers per group.
4. Set the number of sets, points to win a set and winning margin. Enable an age range if needed.
5. Choose BYE or lucky losers, the third-place rule, and whether clubmates may share an automatic group. Save.

Age limits show a warning; organizers may confirm exceptions. Agree the rules with your tournament organizers before starting.

## 4. Register participants

1. Open a category, then Registrations.
2. Choose players and save their registrations. For doubles, build a pair of two different players.
3. Repeat for every category. A player may enter several categories.
4. Check names, clubs and participant counts before creating the draw.

## 5. Confirm arrivals

1. When a player arrives, mark them as arrived in Registrations.
2. Arrival applies across that tournament. Confirm both doubles members.
3. Withdraw registrations for players who drop out before the category starts.

Before the first result, the app checks arrivals. An explicit organizer override allows starting without every arrival; it does not enable collecting payment from unconfirmed arrivals.

## 6. Record entry fees

1. Open the tournament Cash desk.
2. For an arrived player, select the categories they are paying for and record payment.
3. Check outstanding balances and payments. Unconfirmed arrivals show an expected amount.
4. Use the refund action if you return money.

The cash desk remains available after tournament completion.

## 7. Create and check the draw

1. Open category Settings and find Seeds and arrangement.
2. Add seeds in order, strongest first, if applicable.
3. Choose automatic or manual arrangement, generate it, check every place, then save the draft.
4. Open Groups for group standings and Draw for the knockout bracket. Direct knockout has no group phase.
5. Use Draw → Edit to change opening-round places. Group knockout editing is available after all groups finish and standings are resolved.

If club separation cannot find a layout, check club names, seeds and group count, or choose a manual layout.

## 8. Make a backup

1. Open Backups in the left menu.
2. Choose Create backup before matches begin.
3. Export a copy and copy the exported file elsewhere, such as a USB drive, if needed.

A backup includes this tournament and the rest of the application database.

## 9. Enter match results

1. Open category Matches and choose the group and round or knockout stage.
2. Choose Edit on the correct match. If assigning a table, enter its number and save the table first.
3. Enter each set’s points, such as 11:7, 11:9 and 11:5. Required set wins depend on the category rules.
4. Use Played match for a normal ending. Choose Retired for withdrawal during a match or Walkover for a no-show, then choose the winner.
5. Save the result and check that the correct winner is shown.

Saved results update group standings and subsequent knockout matches. Do not enter extra sets once the match has been decided.

## 10. Finish groups and check qualifiers

1. If using groups, enter every group match and open Groups.
2. If standings remain tied, check results and confirm a manual ranking if needed.
3. Check qualifiers and lucky-loser places in Draw. Automatic selection waits for every group to finish.
4. For manual selection, use Draw → Edit to choose an entrant or BYE. Resolve any tied automatic candidates at the final available place manually.

BYE means automatic advance. A lucky loser is an entrant below the qualification cutoff who receives an extra place. Automatic filling uses BYE for remaining places if there are not enough candidates.

## 11. Complete each category

1. Enter knockout results through the final, including a bronze match if the rules require one.
2. Open Results and check final standings. The app lists anything still needed.
3. Choose Complete category and confirm. Repeat for all categories.

Completion locks registrations, rules, draws and results. Reopen a category in Results before making corrections.

## 12. Complete the tournament and save reports

1. Open tournament Overview and check that every active category is complete.
2. Choose Complete tournament and confirm.
3. Where report controls are available, use Print / PDF, CSV or HTML to save or print reports.
4. Create another backup and export it to a safe location.

For corrections after tournament completion, reopen the tournament in Overview, then the category in Results. Confirm both completions again afterwards.

## If you get stuck

### I entered the wrong result.

Edit the same match and save the correction. If subsequent participants change, the app asks before clearing dependent results. Check those matches and enter valid results after confirmation.

### A player withdrew after the category started.

Keep the registration. Record Retired or Walkover in the affected matches and choose the winner. Started categories cannot be removed.

### I want a new draw or scoring rules after play starts.

A new draw requires confirmation and starts without previous scores or table assignments. Old records stay in history. Scoring changes also require confirmation: old results keep their original rules; subsequent entries and corrections use the new rules.

### Where can I see changes?

Open History in the left menu. Newest actions appear first. Filter by tournament, history type or action, then expand record details.

### How do I restore a backup?

Open Backups and choose Restore data or Restore from file. This replaces the whole database, not just one tournament. The app saves the current database first, then reloads and closes open tabs.

## What do these words mean?

- **Category:** A separate competition within a tournament, such as singles 40+ or doubles.
- **Seed:** A participant ranked by the organizer for draw placement.
- **Knockout:** Winners advance; losers leave the contest for first place.
- **Set:** One part of a match. A match is won by winning the required number of sets.
